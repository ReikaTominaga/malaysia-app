# Malaysia 旅行英語 + マレー語 / スペイン語アプリ

英語 + 現地語（マレー語 or スペイン語）を旅行前に練習するアプリです。
サイドバーの「学習する言語ペア」で **英語+マレー語** ⇔ **英語+スペイン語** をいつでも切り替えられます（1画面に両方は出ません）。

## 起動方法

**`index.html` をダブルクリックするだけ。**  
Node.js・Python・サーバー不要です。Chrome推奨。

---

## 主な機能

| 機能 | 説明 |
|------|------|
| 言語ペア切り替え | サイドバー / 設定ページからマレー語⇔スペイン語をいつでも切り替え |
| フレーズ集 | シーン別フレーズを英語＋選択中の言語の音声つきで確認 |
| クイズ（英語） | リスニング4択 / 英語発音チェック / スピーキング確認 |
| クイズ（第二言語） | 選択中の言語（マレー語 or スペイン語）のリスニング4択 / スピーキング練習 |
| AIロールプレイ | Anthropic APIを使ったシーン別英語会話練習 |
| ブックマーク | 苦手なフレーズをまとめて復習 |
| 今日のフレーズ | 毎回起動時にランダムで1フレーズをピックアップ |
| 豆知識 | マレーシア豆知識 / スペイン豆知識（選択中の言語ペアに応じて切り替え） |

## よく編集するファイル

### フレーズを追加したい → `js/data.js`
```js
{ id: 35, scene: 'restaurant', jp: '水をください', en: 'Can I have some water?', kana: 'ボレ ミンタ アイル?', ms: 'Boleh minta air?', es: '¿Me trae agua, por favor?', kanaEs: 'メ トラエ アグア ポル ファボル?' },
```
`kana` はマレー語の読み方、`kanaEs` はスペイン語の読み方（どちらもカタカナ発音ガイド）です。
`scene` に指定できる値: `greeting` / `airport` / `hotel` / `restaurant` / `shopping` / `transport`

### 豆知識を追加・編集したい → `js/data.js`
マレーシア豆知識は `TIPS_MS`、スペイン豆知識は `TIPS_ES` に配列で定義しています。
言語ペアごとのUI文言（サイドバーの説明文・ページタイトルなど）は `TARGET_LANGS` にまとめてあります。

### 色を変えたい → `css/base.css`
```css
:root {
  --teal: #1D8B6F;   /* メインカラー */
  --bg:   #F7F4EF;   /* 背景色 */
}
```

## AIロールプレイを使う場合

1. [Anthropic Console](https://console.anthropic.com) でAPIキーを取得
2. アプリ左下の「Anthropic API Key」欄に入力
3. APIを使うたびにサイドバーで料金がリアルタイム表示されます（月次で自動リセット
